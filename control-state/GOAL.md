# System Goal: Vibe Coding & Hybrid Agile/Waterfall Development OS (vibe-os)

## Objective
Build an interactive, real-time visual control platform for AI-assisted development (Vibe Coding).
`vibe-os` bridges continuous agile velocity (rapid agent code generation & log streaming) with waterfall governance gates (human sign-off before deployment).

## Core Capabilities
1. **Real-time Log Streaming**: Low-latency WebSocket broadcasting from agent execution loops to browser UI.
2. **State Machine Governance**: Clear distinction between Agile execution iterations and Waterfall approval gates.
3. **Markdown-driven Source of Truth**: All goals, tasks, handoff summaries, and human decisions are persisted in human-readable Markdown files.
